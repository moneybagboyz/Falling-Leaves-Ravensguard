# Redesign concept pages

Source for the visual reference pages used while planning the redesign (see `docs/REDESIGN_PLAN.md`).
Open any file in a browser; everything is drawn by code in the page.

- `ravensguard-tileset.html`: **current look**, style sheet v1. UltiCa-style 32 px pixel tiles, layered 32×64 characters, day/night street, ford skirmish, pixel UI.
- `ravensguard-look-options.html`: art-direction exploration (woodcut, manuscript, chiaroscuro, ink map, pixel). Historical.
- `ravensguard-concept-book.html`: the first concept book (woodcut look, first-hour walkthrough). Its visuals are superseded; the play walkthrough still describes the intended game.
